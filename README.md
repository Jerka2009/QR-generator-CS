# QR-generator

RU | EN

---

## Описание (RU)
Простой генератор QR-кодов на C#.
Программа принимает текст (URL, контакты, обычный текст) и создаёт изображение QR-кода в формате PNG.

### Особенности
- Генерация QR-кодов из строки
- Сохранение результата в PNG
- Простой и понятный код на C#

### Требования
- .NET SDK 6.0 или новее

### Установка и запуск
1. Склонируйте репозиторий:
   git clone https://github.com/Jerka2009/QR-generator-CS.git
2. Перейдите в каталог проекта:
   cd QR-generator-CS
3. Соберите и запустите:
   dotnet run

### Использование
Запустите приложение и введите текст для кодирования, затем укажите имя файла для сохранения (например `qrcode.png`).

### Лицензия
MIT — см. LICENSE (если есть).

## Description (EN)
A simple QR code generator in C#.
The program accepts text (URL, contact info, plain text) and creates a PNG image of the QR code.

### Features
- Generate QR codes from a string
- Save output as PNG
- Simple and readable C# code

### Requirements
- .NET SDK 6.0 or newer

### Install & Run
1. Clone the repository:
   git clone https://github.com/Jerka2009/QR-generator-CS.git
2. Change to the project folder:
   cd QR-generator-CS
3. Build and run:
   dotnet run

### Usage
Run the application, input the text to encode, then provide an output filename (for example `qrcode.png`).
