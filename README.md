# QR code generator
Прилоэение на windows которое предоставляет возможность превращать текст в QR-Code.

## Скриншоты
[картинки]

## Возможности
- Преобразование ссылок, текстов и любых символов в QR-Code

## Технологии
- Используется технология шифрования текста разбиения символов на биты и превращение в картинку при помощи библиотеки QRCoder

## Как запустить
Скачиваете последний релиз, разорхивируете в новую папку и запускаете QR-Generator.exe
